# EasLearn AI

**EasLearn AI** is an innovative AI-powered educational application designed to optimize the learning experience through intelligent technology. This project is developed for **KitaHack 2026**, specifically focusing on **United Nations Sustainable Development Goal 4 (SDG 4): Quality Education**.

## 🚀 Project Overview
EduPulse AI leverages Generative AI to provide students with personalized learning support, automated content summarization, and interactive Q&A. Our mission is to bridge the gap in educational resource distribution and tackle the challenges of low learning efficiency.

## 🛠 Tech Stack
* **Frontend:** Flutter (Dart)
* **Backend:** Firebase (Authentication, Firestore, Storage, Github)
* **AI Engine:** Google Gemini API & Python (Backend Processing)
* **Tools:** Git, GitHub, Antigravity

## ✨ Core Features
* **AI Tutoring:** 24/7 instant academic assistance powered by the Gemini API.
* **Course Management:** Seamless synchronization of learning progress and study materials.
* **Automated Note-taking:** Rapid generation of study outlines and key point summaries.
* **SDG 4 Alignment:** Personalized learning paths to ensure inclusive and equitable quality education.

## 📦 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/edupulse_ai.git](https://github.com/your-username/edupulse_ai.git)
    ```
2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
3.  **Environment Setup:**
    Ensure you have your Gemini API credentials configured in your environment variables or `.env` file (ensure this file is ignored by Git).
4.  **Run the application:**
    ```bash
    flutter run
    ```
